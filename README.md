# 网页朗读助手（Chrome 插件）v3.1

把网页文字读给你听：点一下朗读全文，或者选中一段只读一段。
v3 参考 Speechify 的核心体验（页面内播放器、同步高亮、点哪读哪、
选区即读、速度训练），并**内置了三个免费的神经网络中文音色
（Piper 华燕·标准女声 / 超文·男声 / 小雅·温柔女声）**：模型文件直接打包在插件里，
在本机用 WASM 合成语音，**完全离线、不要 Key、不上传任何文字**。

## 隐私（重点，先说清楚）

- 插件自有代码（`content.js` / `background.js` / `popup.js`）**没有任何
  联网调用**：没有 fetch、没有 XMLHttpRequest、没有统计、没有服务器。
  你可以自己在源码里搜这几个词验证。
- 内置离线引擎跑在一个内部页（offscreen）里。该页一加载就给
  `fetch` / `XMLHttpRequest` 装了防火墙：任何 `http(s)` 外部请求直接
  拒绝，只允许读 `chrome-extension://` 的插件本地文件。模型和 WASM
  全部随插件打包（约 118MB，主要是模型 63MB + espeak 数据 18MB +
  ONNX 运行时），底层库就算想回退去 CDN 下载也发不出去。
- 权限只有 `activeTab / scripting / contextMenus / storage / offscreen`，
  **不申请全站常驻访问**，点一次才注入一次页面。
- 唯一的例外是“系统音色”引擎：它用浏览器自带语音，其中标「云端」的
  音色（如 Google 音色）会由浏览器把文字发给厂商服务器合成——这是
  Chrome 本身的行为，不是插件在传。弹窗里已给每个系统音色标注
  「本地 / 云端」，介意隐私就用内置离线引擎或选「本地」音色。
- 想亲手验证：装好后打开一篇文章，**断开网络**再点朗读——离线引擎
  照样读；也可以在 `chrome://extensions` 里打开插件的检查视图看网络
  面板，全程不会有任何外部请求。

## 功能（v3）

- **双引擎**：① 内置 Piper 中文离线音色（默认，断网可用），三个音色可换：
  华燕·标准女声、超文·男声、小雅·温柔女声；弹窗里还有「情感语录模式」
  一键预设（小雅 + 0.85× 慢速）；
  ② 系统音色（浏览器内置语音，多语言/多音色）。弹窗里随时切换。
- **离线引擎不卡段**：播放当前段时预合成下一段，段与段衔接顺滑；
  语速 0.5–3× 调播放速度实现，可即时生效不用重读；首次使用要等
  几秒初始化（加载 63MB 模型进内存），之后就快了。
- **页面内悬浮播放器**：播放/暂停、上一段/下一段、加减速、进度条、
  剩余时间估算，不用反复开弹窗
- **段落高亮 + 自动滚动跟随**：读到哪段，哪段就高亮并平滑滚动到屏幕
  中央（可在弹窗里关掉跟随）
- **悬停点播**：鼠标停在任意段落上，左侧出现 ▶ 按钮，点一下从那段开始读
- **选区气泡**：选中文字后旁边弹出「▶ 朗读」小按钮，点一下只读选区
- **朗读全文**：按段落提取正文（优先 `<article>` / `<main>`，剔除导航、
  页脚等噪声区），逐段朗读（按句末标点切成 ≤180 字片段）
- **语速（0.5–3×）、音调**可调（音调只对系统音色引擎生效），弹窗里可
  **试听音色**；设置自动保存
- **渐进加速**（借鉴 Speechify 的 speed ramping）：开启后每读 10 段
  语速自动 +0.05，最高到 3×
- **右键菜单**：「朗读选中文字 / 朗读全文 / 停止朗读」
- **快捷键**：`Alt+R` 朗读（有选区读选区，没有读全文）、`Alt+S` 停止
- 关掉弹窗不影响朗读；关掉正在朗读的网页会自动停掉声音

## 与 Speechify 的差距（老实说）

- **音色**：Speechify 是云端 AI 人声（1000+ 音色、60+ 语言）。我们的
  内置音色是三个中文音色、本地神经合成，音质中上，但中英混读时英文
  单词发音会别扭，情感表现也不如云端 AI。胜在免费、离线、隐私。
- **高亮粒度**：Speechify 能逐字高亮；我们做的是段落级高亮。
- **资料库/跨设备同步、PDF OCR、AI 总结问答**：不在 v3 范围。

## 安装（开发者模式加载，不用上架商店）

1. 解压 `page-reader.zip`（或直接用本文件夹）
2. Chrome 地址栏打开 `chrome://extensions`
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选择本文件夹
5. 工具栏会出现蓝色喇叭图标，点开就能用；建议点图钉固定

> 如果之前装过 v1/v2：在 `chrome://extensions` 里找到旧版，点刷新
> 按钮即可更新到 v3（或移除后重新加载本文件夹）。
> 注意：Chrome 的内部页面（`chrome://` 开头、新标签页、扩展商店页面）
> 出于浏览器限制无法朗读，普通网页都可以。

## 它是怎么工作的（结构）

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 清单：`activeTab / scripting / contextMenus / storage / offscreen` 五个权限；CSP 允许插件页加载 WASM（`wasm-unsafe-eval`），脚本仍只能来自插件自身 |
| `content.js` | 注入页面：提取正文 → 切成 ≤180 字片段 → 队列播放、段落高亮、悬浮播放器、向 offscreen 发合成指令 |
| `offscreen.html` + `offscreen/` | 内部页：Piper WASM 合成 + 音频播放。入口源码在 `../piper-build/src/offscreen-entry.js`，用 esbuild 打包（库：`@mintplex-labs/piper-tts-web` + `onnxruntime-web`） |
| `voices/` | 三个 Piper 中文模型（华燕/超文/小雅，各 63MB）+ 配置。超文、小雅是拼音音素模型，用自研拼音前端驱动（`piper-build/src/pinyin.js`，规则对齐官方 `phonemize_chinese.py`，多音字用 pinyin-pro 词典消歧） |
| `wasm/` | piper_phonemize（espeak-ng 音素化，含数据 18MB）+ ONNX Runtime 的 WASM 二进制 |
| `background.js` | Service Worker：右键菜单 + 快捷键转发；管理 offscreen 页的创建；标签页关闭时停掉播放 |
| `popup.*` | 工具栏弹窗（遥控器）：引擎切换、语速/音调/系统音色（带本地/云端标注）、试听、进度显示 |

模型来源与授权：Piper 引擎 MIT 开源；`zh_CN-huayan-medium` 音色来自
`rhasspy/piper-voices` 公开仓库。个人使用免费；若将来公开分发或商用，
请再核对该音色的训练数据授权条款。

## 已知限制

- 内置音色只有中文（女声×2、男声×1）；读英文文章请切系统音色（或等后续
  版本加英文离线音色，包体会再大约 63MB）。超文/小雅对英文单词会直接跳过
  不读（与官方 Piper 行为一致），华燕能读少量英文。
- 首次点朗读要等几秒初始化；配置很低的电脑合成可能慢于播放速度，
  长段落之间会略有停顿。
- 少数排版特殊的页面（正文全在 canvas/图片里）提不到正文，用
  「朗读选区」手动选中即可。PDF 请先在 Chrome 里打开，部分可读。

## v3.2.0 修复说明（重要）
在真实 Chrome 里复现后找到“没声音”的根因：**Chrome 会在音频停止约 30 秒后回收离线合成页**，
且回收不留任何报错——合成页没了，朗读指令就石沉大海。修复：
- 后台每次启动合成前先做存活验证（ping），发现已被回收立即重建；
- 朗读 25 秒无回音时自动重启合成页重试一次；试听同理；
- 三个音色（华燕/超文/小雅）均已在真实 Chrome 157 中实测可出声，含“被回收后自动恢复”场景。
